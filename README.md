# Low Code Lab Assignments and Projects

A collection of low-code application projects and laboratory assignments
developed using **Zoho Creator**.

This repository contains the **ConsentLedger** project and the **Hotel
Room Booking & Front Office Management** lab assignment work, along with
their related documentation and screenshots.

## Repository Contents

### 1. ConsentLedger

**ConsentLedger: A Consent Lifecycle and Data Principal Rights
Management System**

A Zoho Creator-based academic project designed to demonstrate consent
lifecycle management, data principal rights request handling, breach
incident tracking, and related administrative records.

Main components:

-   Person Register
-   Consent Records
-   Rights Requests
-   Breach Incidents
-   Action Log
-   Rule Configuration
-   ConsentLedger dashboard and reports
-   Deluge workflows and breach-risk prediction integration

The project is intended as an academic prototype for demonstrating
selected data protection and privacy-management processes.

### 2. Hotel Room Booking & Front Office Management

A Zoho Creator low-code application developed as part of the laboratory
assignments.

Main components include:

-   Room Booking Form
-   Room Inventory
-   Booking and inventory reports
-   Dashboard summary
-   Deluge scripts and workflow configurations

The lab work is documented in five separate assignment areas:

1.  Basic Fields
2.  Advanced Fields
3.  Page Elements
4.  Report Types
5.  Workflows
